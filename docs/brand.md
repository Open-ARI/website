# Logo and artwork

<img class="openari-logo" :src="withBase('/brand/openari-logo-web.png')" alt="OpenARI mosaic logo: overlapping photo and filmstrip with a checkmark" width="582" height="496">

Shaun Murphy designed this version of the OpenARI logo in CorelDRAW. Its uneven
mosaic texture is intentional. The photo, filmstrip, and checkmark represent the
project's focus on media verification.

The logo identifies the project. It is not a verification result or a statement
of supported formats. See [compatibility and status](status.md) for current support.

The published PNG and CorelDRAW copies have been cleaned of embedded descriptive
metadata, including author details, dates, document identifiers, and local export
paths. The CorelDRAW file retains the drawing structure and color profiles needed
to edit and render the artwork. The PNG master preserves the original pixels and
transparency. Website sizes are derived from that master.
